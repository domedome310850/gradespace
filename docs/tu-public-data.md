# Thammasat public academic source snapshot — 2026-11-26
This is a static, partial, source-backed snapshot used by the existing TU catalog; it is not an official live registrar feed. No student information or personal contact information is collected.

- [General Education Program revised 2566](https://www.tuacrd.in.th/tadmin/upload_file/doc_6981a6612243e.pdf), printed pp. 2–21: 229 listed courses across five groups (48, 76, 44, 47, 14). Parsed Thai/English code pairs and stated credits, preserved the existing 53 rows after checking group and credit agreement. RT277 handled separately because its credits are on the English line. PDF extraction can introduce title/spacing errors; a full visual row-by-row verification is pending. The 2566 structure requires at least 30 credits, subject to faculty rules.
- [TU announcement about the 2570 curriculum](https://sdgs.tu.ac.th/th/2026/09/30/thammasat-2027-general-education-outcome-based-education-th/): incoming 2570 students use at least 24 credits (15 central + at least 9 faculty). No 2570 course list is inferred or substituted.
- [TBS BBA international curriculum 2023](https://bba.tbs.tu.ac.th/coursedescription.php?CourseYear=2023): 208 course headings extracted, 204 prerequisite lines captured as source text, not an eligibility engine. Overlapping GenEd courses are deduplicated in autocomplete and the picker. These are BBA-listed courses, not all TBS courses and not a declaration that every course is required.
- [Social Administration syllabus archive](https://socadmin.tu.ac.th/document14): JA315 (1/2568), SW231 (2/2568), SW366 (1/2569). Store course, term, source URL, published section scope (blank if not stated), assessment weights, grade floors, and explicitly stated attendance requirements. The reference panel never applies these policies or changes saved marks automatically. SW231 and JA315 documents contain inconsistent dates/years elsewhere; no exam dates imported. SW366 has no stated section, so it cannot be matched safely to a specific offering. Integer score bands are displayed as stated floors; fractional score treatment is not inferred. A/B/C grade cutoffs differ by course; do not use these as TU defaults.
- Total distinct catalog codes: 429. No live offering/section/seat data, no automatic schedule sync, no 2570 catalog, no complete program requirements, no production deployment.
- Test: `cd tests && node tu-catalog.mjs`; `npm test` runs this with existing planning and browser smoke. Browser tests require dependencies/Chromium. Review data against original PDF before promoting snapshot as complete.
